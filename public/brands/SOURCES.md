# Third-party brand assets

These marks identify compatible products. They remain the property of their respective owners and are not covered by this project's MIT license. Their display does not imply endorsement.

- `claude.svg`: Claude symbol extracted from the official Claude wordmark on https://claude.com/product/claude-code (the standalone symbol occupies its original 125 × 125 area). The original path and color are preserved; the site displays a monochrome silhouette using a CSS mask.
- `openai.svg`: OpenAI mark from the official header SVG at https://developers.openai.com/codex/. Used to identify OpenAI Codex. Original path and viewBox preserved. Brand guidance: https://openai.com/brand/.

Retrieved 2026-11-12. Files are served locally rather than hotlinked.
